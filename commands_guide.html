Bulls & Bears

Official Discord Trading Floor & Administrator Command Guide

Simulation Length: 6 Rounds (R0–R5)
Market Pool: 20 → 30 Stocks | 100 Float
Core Tournament Constraints: All teams manage a starting balance of $100,000.00 in virtual cash[cite: 1, 2, 4]. Every equity has a hard market ceiling of 100 available shares[cite: 4]. Trades are permitted strictly when the round trading window is active (10 minutes)[cite: 2, 4]. Short selling is blocked[cite: 2].
Channel: #trading-floor Traders & Public Market Desk
/register Trader Setup
Registers the designated team account, sets starting liquid balance to $100,000, and enables trading access[cite: 1, 4].
Parameter Type Required Description
team_name String Yes Official name of your registered team (maximum 2 members per team)[cite: 1, 2].
Example: /register team_name: Alpha Capital
/portfolio Player Query
Displays current available cash, total net asset value, cumulative P/L, and an itemized breakdown of owned stock positions[cite: 4].
Example: /portfolio
/market Public Board
Returns a live list of all active stocks, their current trading price, and remaining float available for purchase from the market pool[cite: 4].
Example: /market
/buy Execution
Purchases shares from the public market pool at current market price. Checks cash reserves, available float, and window status[cite: 4].
Parameter Type Required Description
ticker String Yes Ticker symbol of the stock (e.g., NVDA, AAPL, MSFT)[cite: 3, 4].
shares Integer Yes Whole number of shares to buy (must not exceed market float)[cite: 2, 4].
Example: /buy ticker: NVDA shares: 15
/sell Execution
Sells owned shares back to the open market at current market price. Credits team cash balance and restores the public float[cite: 4].
Parameter Type Required Description
ticker String Yes Ticker symbol of the stock being sold[cite: 4].
shares Integer Yes Number of shares to sell (cannot exceed owned holdings)[cite: 2, 4].
Example: /sell ticker: AAPL shares: 10
Channel: #swap-desk Peer-to-Peer Stock Swaps
/swap Negotiated Trade
Submits a peer-to-peer stock-for-stock swap proposal with an interactive confirmation widget[cite: 2, 4]. The counterparty must click Accept Swap within 90 seconds to settle[cite: 2, 4]. No cash adjustments permitted[cite: 2, 4].
Parameter Type Required Description
target User Mention Yes Discord tag of the opposing team's designated trader account[cite: 4].
give_ticker String Yes Ticker symbol of the stock you are transferring[cite: 4].
give_shares Integer Yes Number of shares you will give to the target[cite: 4].
receive_ticker String Yes Ticker symbol of the stock you are demanding in return[cite: 4].
receive_shares Integer Yes Number of shares you demand from the target[cite: 4].
Example: /swap target: @TraderBob give_ticker: NVDA give_shares: 20 receive_ticker: TSLA receive_shares: 15
Channel: #admin-console Restricted Organizer Controls
/admin reset_game Organizer
Wipes existing transactions, restores initial 20-stock board, resets floats to 100, and prepares database for a fresh tournament run[cite: 3, 4].
Example: /admin reset_game
/admin start_round Organizer
Sets active round, releases the round's macroeconomic news flash into #news-flash, unlocks the 10-minute trading window, and unlocks the 10 expansion stocks if round ≥ 2[cite: 3, 4].
Parameter Type Required Description
round_number Integer Yes Target round index: 0, 1, 2, 3, 4, or 5[cite: 3].
Example: /admin start_round round_number: 1
/admin close_trading Organizer
Immediately disables trading. All `/buy`, `/sell`, and `/swap` requests will be rejected by the bot until the next round starts[cite: 4].
Example: /admin close_trading
/admin apply_round_prices Organizer
Calculates and updates stock prices according to the current round's master sheet movements and notifies traders in #market-board[cite: 3, 4].
Example: /admin apply_round_prices
/admin liquidate Tournament End
Locks trading permanently, liquidates every team's held shares at current market prices, credits cash, and publishes the final winners' podium[cite: 2, 4].
Example: /admin liquidate
Standard Round Execution Flow
Step 1
Open Round
Run /admin start_round. Bot announces news in #news-flash and starts trading[cite: 4].
Step 2
10-Min Window
Participants negotiate in the room and execute orders on Discord[cite: 2, 4].
Step 3
Close Market
Run /admin close_trading when timer runs out to freeze order execution[cite: 4].
Step 4
Update Valuations
Run /admin apply_round_prices to adjust stock prices and update portfolios[cite: 3, 4].
